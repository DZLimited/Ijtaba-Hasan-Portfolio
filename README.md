

# 🧠 Ijtaba Hasan — AI Developer Portfolio

A modern and responsive developer portfolio showcasing Ijtaba Hasan's expertise in Artificial Intelligence, Machine Learning, NLP, and React Native development. This portfolio presents his skills, projects, and professional journey as a final-year BSAI student.

## 🔍 Overview

This portfolio was designed to:

* Showcase AI/ML/NLP-based real-world projects
* Highlight technical skills and professional experience
* Offer an interactive, mobile-friendly UI with smooth animations
* Act as a personal brand for job applications and networking

## 🚀 Features

* **Fully Responsive** — Optimized for mobile, tablet, and desktop
* **Animated UI** — Smooth scroll and motion effects using Framer Motion
* **Project Highlights** — Real AI/ML/NLP projects with tech stacks
* **Skill Stack** — Clear breakdown of technical skills
* **Minimal Design** — Clean and accessible design for better user experience

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS
* **Animation:** Framer Motion
* **Icons:** React Icons
* **Build Tool:** Vite
